## 1. 画面遷移

```
[利用者]
入力画面(S-01) → 確認画面(S-02) → 完了画面(S-03)
      ↑_____________|（戻る）

[管理者]
ログイン画面(S-04) → お問い合わせ一覧画面(S-05) → お問い合わせ詳細画面(S-06) → 返信画面(S-07)
                              ↑_______________________________|（一覧へ戻る）
                              │
                              └→ 管理者アカウント管理画面(S-08)

ログイン画面(S-04) → パスワード再設定依頼画面(S-09) →（メールのリンク経由）→ 新しいパスワード設定画面(S-10) → ログイン画面(S-04)
```

要ログインの管理画面（S-05〜S-08）は共通の☰メニューから、メール送信ログ画面(S-11)・運用マニュアル閲覧画面(S-12)・管理者アカウント管理画面(S-08)・ログアウトのいずれにも相互に遷移できる（詳細は14章「共通ヘッダー」参照）。

未ログイン状態でS-05〜S-07に遷移しようとした場合は、S-04（ログイン画面）へリダイレクトする（要件 F-13）。

**利用者向け画面（S-01〜S-03）には、S-04（ログイン画面）への導線（リンクやボタン）を意図的に設置しない。** 一般の訪問者の目にログイン画面が触れないようにするための設計判断であり、管理者はログイン画面のURLを直接開く（担当者から個別に共有されたURLをブックマークする等）運用とする（2026-08-20の確認事項）。ログイン画面自体が第三者に見つかっても、認証を突破しない限り内部情報は閲覧できないため（要件 F-13、8.9のロック機能等）、URLが非公開であることに安全性を依存しているわけではない。

### 画面状態

| 状態 | 内容 |
|------|------|
| 初期表示 | ログインID/メールアドレス・パスワードともに空欄 |
| 認証失敗 | 「IDまたはパスワードが正しくありません」と表示（ログインID・メールアドレス・パスワードのどれが誤りかは特定させない）。ログインIDとメールアドレスのどちらを入力しても同じ欄で受け付ける（要件 F-10、2026-08-14のヒアリングで追加。ログインIDを忘れた場合の救済手段） |
| アカウント無効時 | 管理者アカウントが無効化（is_active=0）されている場合も「IDまたはパスワードが正しくありません」と表示する（アカウントの有無・状態を外部から推測できないようにするため、認証失敗時と同一メッセージにする） |

| 認証成功 | 新しいセッションを発行し、S-05（一覧画面）へ遷移する |
| パスワードをお忘れの方はこちら押下 | S-09（パスワード再設定依頼画面）へ遷移する（要件 F-24） |

## 6. S-05 お問い合わせ一覧画面

```
┌────────────────────────────────────────────────────────────────────┐
│  Chat Plus+  │  お問い合わせ一覧                                  ☰ │
├────────────────────────────────────────────────────────────────────┤
│ 対応状況[すべて▼] サービス項目[すべて▼] キーワード[        ][検索] 表示件数[20件▼] │
├────────────────────────────────────────────────────────────────────┤
│                    « 1  2  3 … »（ページネーション・上部）                  │
├────────────────────────────────────────────────────────────────────┤
│対応状況│会社名│氏名(短縮)│メールアドレス(短縮)│サービス項目│ChatPlusについて│内容(抜粋)│登録日時│
├────────────────────────────────────────────────────────────────────┤
│未対応  │○○(株)│山田…│xxx@...     │[ChatPlus]│利用中          │.......│08/01  │
│対応済  │△△(株)│佐藤…│yyy@...     │[FAQPlus] │検討中          │.......│07/30  │
│  ：（行クリックで詳細画面 S-06 へ遷移）                                    │
├────────────────────────────────────────────────────────────────────┤
│                    « 1  2  3 … »（ページネーション・下部）                  │
└────────────────────────────────────────────────────────────────────┘
```

`[ChatPlus]`等はサービス項目を種類ごとに色分けしたバッジ表示を表す（配色は15章参照）。「☰」は共通メニューアイコンを表す（詳細は14章「共通ヘッダー」参照）。

一覧に表示する列は、会社名・氏名・メールアドレス・サービス項目・ChatPlusについて・内容(抜粋)・登録日時・対応状況とする。**ご担当はここでは表示せず、詳細画面（S-06）でのみ確認する**（要件 F-14、2026-08-13のヒアリングで確定。プルダウン等の絞り込み条件も含め、一覧画面の情報量が多すぎて見づらいとの指摘を受けての変更）。対応状況の列は一覧の左端に配置する。

会社名・氏名・メールアドレス列は、内容(抜粋)列と同様に一定の文字数を超える場合は省略記号（…）で短縮表示する（クリックすれば詳細画面S-06で全体を確認できる）。あわせて一覧テーブル全体の横幅を広げ、ChatPlusについて列までスクロールなしで見えるようにする（要件 F-14、2026-08-14のヒアリングで追加）。

ページ切り替え（ページネーション）は、一覧が長くなった際に上までスクロールし直さなくて済むよう、一覧テーブルの上下両方に同じものを表示する（要件 F-14、2026-08-14のヒアリングで追加）。

### 画面状態

| 状態 | 内容 |
|------|------|
| 初期表示 | 登録日時の新しい順に表示。対応状況・サービス項目の絞り込みはいずれも「すべて」、表示件数は20件 |
| 絞り込み | 対応状況・サービス項目それぞれのプルダウンと、キーワード検索（会社名・氏名・メールアドレス対象）を組み合わせて絞り込む。プルダウンは「対応状況」「サービス項目」のようにラベルを明示し、「すべて」という選択肢だけが単独で表示されて分かりにくくならないようにする |
| レイアウト | 対応状況・サービス項目・キーワード・表示件数の絞り込み欄は、横幅を圧迫しないよう1行に収まるコンパクトな配置とする（各プルダウンの選択肢文言は短い名称のみを表示し、ご担当のような長い文言の項目は絞り込み欄に含めない）。一覧テーブル自体は横幅を広く取り、氏名・メールアドレスは短縮表示にすることでChatPlusについて列までが折り返しなく見えるようにする |
| 表示件数変更 | 「20件」「50件」「100件」から選択できる（デフォルト20件）。変更時は1ページ目に戻る |
| データなし | 「該当するお問い合わせはありません」と表示 |
| 行クリック | 対象のS-06（詳細画面）へ遷移する |
| ページ切り替え | テーブル上部・下部のどちらのページネーションを操作しても同様にページが切り替わる |

## 14. レイアウト方針

- 利用者向け画面（S-01〜S-03）はPC・スマートフォンどちらでも1カラムの縦並びレイアウトとし、最大幅は480px程度、画面中央に配置する
- 管理者向け画面（S-04〜S-12）はPCでの利用を主とするが、スマートフォンでも操作できるようレスポンシブ対応する。一覧画面（S-05）は列数が多いため、スマートフォン幅では横スクロール、またはカード形式表示に切り替える
- S-09・S-10はS-04と同様、入力項目が少ないシンプルな1カラムレイアウトとする
- ボタンはタップしやすいよう、上下の余白を十分に確保する

### 共通ヘッダー（2026-08-13の実装レビューで追加）

- S-01〜S-04・S-09・S-10（ログイン前後の単独操作画面）: 画面上部に「Chat Plus+」ロゴのみを表示する細いヘッダーバーを置く
- S-05〜S-08・S-11・S-12（要ログインの管理画面）: 画面上部にロゴ・画面タイトルに加え、右端に「☰」メニューアイコンを表示する。押すと「管理者アカウント管理」「メール送信ログ」「運用マニュアル」「ログアウト」の一覧がドロップダウン表示される（当初はこれらをヘッダーに直接並べて表示していたが、項目数が多く煩雑との指摘を受けて2026-08-13にメニュー形式へ変更した）
